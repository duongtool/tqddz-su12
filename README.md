# Ôn tập Lịch sử 12 – Kết nối tri thức

Website ôn tập tương tác đầy đủ 6 Chủ đề SGK Lịch sử 12.

## Cách xem

Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages.

## Cấu trúc

- `index.html` – Trang chủ
- `css/`, `js/` – Giao diện & tương tác (Flashcard, Quiz, Ghép đôi)
- `chu-de-1/` … `chu-de-6/` – Nội dung từng chủ đề + bài học

## Chủ đề

1. Thế giới trong và sau Chiến tranh lạnh  
2. ASEAN  
3. Cách mạng tháng Tám & kháng chiến  
4. Đổi mới từ 1986  
5. Đối ngoại Việt Nam  
6. Hồ Chí Minh trong lịch sử Việt Nam
